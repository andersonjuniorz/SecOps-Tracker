# SecOps Tracker 🛡️

Sistema de monitoramento e gestão de disponibilidade de viaturas, desenvolvido para fins de estudo e portfólio utilizando Java 21 e Spring Boot.

## 🚀 Tecnologias Utilizadas
* **Java 21**
* **Spring Boot**
* **Spring Data JPA / Hibernate**
* **MySQL**
* **Maven**

## 📋 Funcionalidades (CRUD)
* Cadastro de novas viaturas com controle de placa e status operacional (`DISPONIVEL`, `EM_MANUTENCAO`, etc.).
* Listagem de todas as viaturas cadastradas.
* Busca por ID e por Placa.
* Atualização de dados da viatura.
* Exclusão de registros com validação de existência.
